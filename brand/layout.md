# Layout

One centred column on an empty page, read from top to bottom.

## Rules

- **Keep content in one centred column no wider than the `space.column` token (560px).** Because one column has one reading order, for people and for agents parsing the page.
- **Open with the mark, the name and the statement, then one way to get in touch.** Because a visitor should know who this is and what it does before scrolling.
- **Build sections as registers: a mono label, then hairline rows.** Because rows make a list scannable without decoration.
- **Separate sections with space (the `space.section` token), not boxes or colour.** Because space is the only divider that never competes with content.
- **Give every page a plain-text twin for agents: llms.txt or a markdown copy.** Because agents read text more reliably than layout, and the twin should say exactly what the page says.
