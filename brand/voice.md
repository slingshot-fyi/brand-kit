# Voice

Slingshot writes like a plain, careful engineer: specific claims, full sentences, nothing inflated.

## Rules

- **Make only claims that are true today.** Because an agent repeats whatever the kit says, so an aspiration written as a fact becomes a false claim on every surface it touches.
- **Say that unfinished work is being built.** Because "is building" is honest about an early company, and readers trust the rest of the page more for it.
- **Write one idea per full sentence.** Because a run of clipped fragments ("Fast. Simple. Secure.") reads as machine-written and says nothing about how or why.
- **Give the reason with the claim.** Because a reader can check a reason, and a bare adjective asks them to take it on faith.
- **Use no em dashes; use a full stop, a colon or a comma.** Because the brand's punctuation is plain, and the dash is the most common tell of generated copy.
- **Never invent customers, numbers, quotes or funding.** Because one invented fact discredits every true one beside it.

## Words

| Say | Instead of | Because |
| --- | --- | --- |
| agentic brand system | AI-powered branding | It names the deliverable, not the technology. |
| kit | brand book, guidelines | A kit is files that are read and used; a book is looked at. |
| tokens | brand colours | Tokens are the values that code and agents actually use. |
| we are building | we offer, we provide | It is true while the system is still in progress. |
